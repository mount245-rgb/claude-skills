# 키움 영웅문4 조건검색식 생성 스킬

유튜브 링크, 전략 스크립트, 또는 매매 기법 설명을 받아 키움 영웅문4(HeroMain4) 조건검색식으로 변환한다.

---

## 입력 처리

### 유튜브 URL이 제공된 경우
1. `youtube-transcript` MCP로 자막 추출
2. 전략의 진입/청산 조건, 사용 지표, 주기(timeframe)를 파악
3. 아래 변환 로직 적용

### 텍스트/스크립트가 제공된 경우
1. 전략 설명에서 조건들을 직접 추출
2. 아래 변환 로직 적용

---

## 변환 로직

### 1단계: 전략 분석
다음 항목을 추출한다:
- **주기**: 일봉/주봉/분봉(1분/3분/5분/10분/15분/30분/60분)
- **지표**: 이동평균선(MA), RSI, MACD, 볼린저밴드, 스토캐스틱, CCI, 거래량 등
- **조건 타입**: 골든크로스, 정배열, 돌파, 비교, 범위, 추세, 반전
- **가격 조건**: 신고가, 등락률, 갭, 캔들 패턴
- **거래량 조건**: 거래량 폭발, 전일 대비 비율 등
- **필터**: 시가총액, 주가 범위, 거래소 구분 등

### 2단계: 조건 분류
각 조건을 6개 대분류 중 하나로 분류:
1. 범위지정
2. 시세분석
3. 기술적분석
4. 패턴분석
5. 재무분석
6. 순위분석

### 3단계: 영웅문4 조건식 포맷으로 출력

---

## 조건식 표기 형식

```
[주기] N봉전 [지표/조건]
```

- **주기**: [일], [주], [월], [1분], [3분], [5분], [10분], [15분], [30분], [60분]
- **N봉전**: 0봉전(현재봉), 1봉전(직전봉), 2봉전...
- **이내**: N봉이내 = 현재부터 N개 봉 포함 범위

---

## 영웅문4 조건식 전체 레퍼런스

### [범위지정]
- **코스피/코스닥 구분**: 거래소 선택
- **자본금**: 범위 지정
- **시가총액**: 범위 지정
- **상장주식수**: 범위 지정
- **주가범위**: 최소~최대 가격
- **거래량**: 범위 지정
- **액면가**: 범위 지정
- **상장일**: 특정 기간 내 상장 종목
- **증거금률**: 범위 지정
- **기타종목구분**: 우선주/ETF/REITS 제외 등
- **특이종목구분**: 관리종목/투자경고 등 제외
- **유통주식수**: 범위 지정
- **검색시간**: 특정 시간대만 검색

### [시세분석 - 가격조건]
- **주가범위**: 현재가 범위
- **주가등락률**: `[일] N봉전 시가/종가대비 M봉전 종가 X%이상/이하/범위`
  - 예: `[일] 0봉전 시가대비 0봉전 종가 등락률 10%이상` (장대양봉)
- **주기별 주가등락률 비교**: 다른 주기 간 가격 비교
  - 예: `[일] 1봉전 고가대비 [1분] 0봉전 종가 등락률 0%이상` (전일고가 돌파)
- **기간내 등락률**: 특정 기간 등락률
- **기간내 주가위치**: 최고/최저가 대비 현재 위치(0~100%)
- **주가돌파**: `[주기] N봉전 고가/저가/종가를 현재가가 상향/하향 돌파`
  - 공식: 1봉전 종가 < 기준값 < 0봉전 종가 (상향돌파)
- **주가비교**: 두 시점 가격 비교
- **주가비교(3개)**: 세 시점 가격 비교
  - 예: `[1분] 1봉전 종가 < 0봉전 금일고가 = 0봉전 종가` (금일고가 갱신)
- **연속상승하락**: 상승/하락 추세 유지 또는 반전
- **기간내 등락봉수**: `[일] 0봉전 N봉이내 M봉 양봉/음봉/상한/하한 발생`
- **기간내 주가변동폭**: `[일] 0봉전까지 N봉간 최고최저폭 X%이하`
- **신고가/신저가**: `[일] 0봉전 종가가 N봉중 신고가에 X%이내 근접`
- **상한/하한**: 상한가/하한가 발생, 장중상한, 근접
- **상승갭/하락갭**: 전일 종가-당일 시가 갭
- **캔들연속발생**: `[일] 0봉전 N봉 연속 양봉/음봉 발생`
- **변동성완화장치(VI)**: 상승/하락 VI 발동 종목
- **당일 전고점 돌파**: 당일 신고가 갱신 횟수

### [시세분석 - 거래량/거래대금]
- **거래량**: 현재 거래량 범위
- **전일거래량**: 전일 거래량 범위
- **평균거래량**: N일 평균거래량
- **거래량비율**: `[일] N봉전 거래량대비 M봉전 거래량 X%이상`
  - 예: `[일] 1봉전 거래량대비 0봉전 거래량 비율 200%이상` (거래량 2배)
- **기간내 평균거래량비율**: 평균 대비 현재 거래량 비율
- **신고거래량**: 특정 기간 신고 거래량
- **금일 신고거래량**: `[5분] 0봉전 최근 1봉이내 금일 신고거래량 발생`
- **전일동시간대대비 거래량등락률**: 전일 같은 시간대 거래량 비교

### [시세분석 - 호가]
- **총잔량**: 매도/매수 총잔량 범위
- **순매수잔량**: 순매수잔량 범위/이상/이하
- **매도매수잔량비**: (매수총잔량/매도총잔량)*100

### [시세분석 - 예상체결]
- 예상체결가격, 수량, 등락률

### [시세분석 - 외국인/기관]
- 외국인 순매수/매도
- 기관 순매수/매도
- 외국인지분율 변동

### [시세분석 - 체결강도]
- 체결강도 범위/이상/이하/돌파

### [시세분석 - 당일분봉]
- **당일 첫 분봉 캔들연속발생**: `[5분] 첫분봉 기준 1봉 연속 양봉발생`
- **분봉 금일 첫봉대비 주가등락률**: `[5분] 금일 첫봉 고가대비 0봉전 종가등락률 0%이상`

### [기술적분석 - 주가이동평균]
- **주가이동평균돌파**: `[일] 0봉전 종가 N이평 종가 M이평 골든크로스/데드크로스`
  - 예: `[일] 0봉전 종가5이평 종가20이평 골든크로스` (5일선 20일선 골든크로스)
  - 예: `[일] 종가1이평 종가120이평 골든크로스` (현재가 120일선 돌파)
- **주가이동평균배열(3개)**: `[일] 0봉전 5>10>20` (정배열)
- **주가이동평균배열(4개)**: 4개 이평 배열
- **주가이동평균비교**: 두 이평선 비교 (이상/이하)
- **이동평균이격도**: `[일] 0봉전 단기이평 종가N, 장기이평 종가M, X%이내 근접`
  - 예: `[일] 0봉전 단기이평 종가5, 장기이평 종가20, 1%이내 근접 1회이상`
- **가격-이동평균 비교**: 현재가 vs 이평선
- **주가이동평균등락률**: 두 시점 이평선 등락률

### [기술적분석 - 거래량이동평균]
- **거래량이동평균돌파**: `[일] 0봉전 1이평 20이평 골든크로스` (거래량 20일 평균 돌파)
- **거래량이동평균배열**: 3개 거래량 이평 배열
- **거래량이동평균추세**: 거래량 이평 상승/하락 추세

### [기술적분석 - 추세지표]
- **MACD**: 기준선 돌파(Signal 상향돌파), 기준값 돌파(0선 돌파), 추세, 반전
  - MACD OSC 0선 상향돌파: MACD OSC 기준값 돌파 0이상
- **MACD Signal**: 기준값 이상이하, 추세, 반전
- **일목균형표**: 기준선/전환선 돌파, 구름대 돌파, 선행스팬, 후행스팬
- **LRS/LRL**: 선형회귀선 기반 조건
- **Parabolic**: 상승/하락 추세, 반전, 돌파

### [기술적분석 - 모멘텀지표]
- **RSI**:
  - 기준값 돌파: `[일] 0봉전 RSI(14) 30상향돌파` (과매도 탈출)
  - 기준값 이상이하: `[일] 0봉전 RSI(14) 70이상` (과매수)
  - 기준값 범위: `[일] 0봉전 RSI(14) 40~60범위`
  - 추세, 반전
- **Stochastic(fast)**: %K가 %D 상향돌파, 기준값 돌파(20 상향돌파 = 과매도 탈출)
- **Stochastic(slow)**: slow %K/%D 기준
- **CCI**: 기준값 돌파(+100 상향돌파), 이상이하, 범위
- **Momentum**: 기준선/기준값 돌파, 추세
- **ROC**: 기준값 돌파, 범위, 추세
- **TRIX**: 기준선(Signal) 돌파, 추세
- **William's %R**: 기준값 이상이하(-80 상향돌파 = 과매도 탈출)
- **이격도**: 기준값 범위(100±N%)
- **VROC**: 거래량 변화율

### [기술적분석 - 채널지표]
- **볼린저밴드(Bollinger Band)**:
  - 가격 기준선 돌파: 상한선/중심선/하한선 상향/하향 돌파
  - 기준선 근접: 상한선/하한선 N%이내 근접
  - Band Width: 밴드 수축/확장
- **Envelope**: 상한선/하한선 돌파, 근접
- **Pivot**: 피벗 레벨 돌파/비교
- **Price Channel**: 채널 상한/하한 돌파

### [기술적분석 - 변동성지표]
- **DMI**: +DI/-DI 돌파/비교/근접
- **ADX**: 기준값 이상이하(25이상 = 추세 강함)
- **Standard Deviation**: 기준값 이상이하, 범위

### [기술적분석 - 거래량지표]
- **OBV**: 기준선 돌파, 추세
- **VR**: 범위/이상/이하
- **MFI**: 기준값 돌파(80 상향돌파 = 과매수)
- **A/D**: 추세/반전

### [패턴분석]
- 캔들 패턴: 망치형, 역망치형, 도지, 장악형, 하라미, 관통형, 먹구름 등
- 차트 패턴: 이중바닥, 이중천장, 헤드앤숄더, 삼각수렴 등
- 주의: 복잡한 패턴(눌림목, 쌍바닥 등)은 조건검색으로 완벽 구현 어려움. 대신 N봉전 기준 근사 조건 사용

### [재무분석]
- **PER**: 범위/이상/이하
- **PBR**: 범위/이상/이하
- **ROE**: 범위/이상/이하
- **EPS**: 범위/이상/이하
- **매출액/영업이익**: 범위
- **부채비율**: 이하
- **시가총액**: 범위

### [순위분석]
- 전일대비 주가등락률 순위
- 거래량 순위 (상위 N위)
- 거래대금 순위
- 체결강도 순위
- 외국인순매수 순위
- MACD(12,26,9) 순위 등
- 주의: 순위 검색은 일봉 기준 고정, 검색 결과는 종목코드 순

## 주요 용어 정의

| 용어 | 설명 |
|------|------|
| 골든크로스 | 단기선이 장기선을 상향 돌파 (1봉전 A<B, 0봉전 A>B) |
| 데드크로스 | 단기선이 장기선을 하향 돌파 (1봉전 A>B, 0봉전 A<B) |
| 정배열 | 단기이평 > 중기이평 > 장기이평 |
| 역배열 | 단기이평 < 중기이평 < 장기이평 |
| 상향돌파 | 1봉전 A < 기준값 and 0봉전 A > 기준값 |
| 하향돌파 | 1봉전 A > 기준값 and 0봉전 A < 기준값 |
| 상승추세(2회이상) | 2봉전A < 1봉전A < 0봉전A |
| 하락추세(2회이상) | 2봉전A > 1봉전A > 0봉전A |
| 0봉전 | 현재 봉 (가장 오른쪽 캔들) |
| 1봉전 | 직전 봉 |
| N봉이내 | 0봉전부터 N개 봉 포함 범위 |

## 17가지 공식 예제

```
예제1: 금일 10% 이상 장대 양봉
→ 시세분석 > 가격조건 > 주가등락률
  [일] 0봉전 시가대비 0봉전 종가 등락률 10%이상

예제2: 오늘 양봉인 종목
→ 시세분석 > 가격조건 > 캔들연속발생
  [일] 0봉전 1봉 연속 양봉 발생

예제3: 10일 중 양봉 5번 이상
→ 시세분석 > 가격조건 > 기간내 등락봉수
  [일] 0봉전 10봉이내 5봉 양봉 발생

예제4: 20일간 5% 이내 횡보
→ 시세분석 > 가격조건 > 기간내 주가변동폭
  [일] 0봉전까지 20봉간 최고최저폭 5%이하

예제5: 금일 고가 갱신 종목
→ 시세분석 > 가격조건 > 주가비교(3개)
  [1분] 1봉전 종가 < 0봉전 금일고가 = 0봉전 종가

예제6: 금일 시가 돌파
→ 시세분석 > 가격조건 > 주가비교(3개)
  [1분] 1봉전 종가 < 0봉전 금일시가 = 0봉전 종가

예제7: 전일 고가 돌파
→ 시세분석 > 가격조건 > 주기별 주가등락률 비교
  A: [일] 1봉전 고가대비 [1분] 0봉전 종가 등락률 0%이상
  B: [일] 1봉전 고가대비 [1분] 1봉전 종가 등락률 -0.01%이하

예제8: 5일 내 상한가 경험 종목
→ 시세분석 > 가격조건 > 기간내 등락봉수
  [일] 5봉이내에서 1봉 상한 발생

예제9: 20일 신고가에 1% 이내 근접
→ 시세분석 > 가격조건 > 신고가
  [일] 0봉전 종가가 20봉중 신고가에 1%이내 근접

예제10: 상승 VI 발동
→ 시세분석 > 가격조건 > 변동성완화장치(VI)
  시장구분[전체], 발동방향[상승], VI종류[전체], 상태[발동]

예제11: 전일 거래량 대비 현재 10분봉 거래량 10% 이상
→ 시세분석 > 거래량/거래대금 > 거래량비율
  [일] 1봉전 거래량대비 10분 0봉전 10%이상

예제12: 5분봉 금일 최고 거래량
→ 시세분석 > 거래량/거래대금 > 금일 신고거래량
  [5분] 0봉전 최근 1봉이내 금일 신고거래량 발생

예제13: 5일선이 20일선 골든크로스
→ 기술적분석 > 주가이동평균 > 주가이동평균돌파
  [일] 0봉전 종가5이평 종가20이평 골든크로스

예제14: 현재가가 120일선 상향돌파
→ 기술적분석 > 주가이동평균 > 주가이동평균돌파
  [일] 종가1이평 종가120이평 골든크로스

예제15: 5·10·20일선 정배열
→ 기술적분석 > 주가이동평균 > 주가이동평균배열(3개)
  [일] 0봉전 5>10>20

예제16: 5일선과 20일선 1% 이내 수렴
→ 기술적분석 > 주가이동평균 > 이동평균이격도
  [일] 0봉전 단기이평 종가5, 장기이평 종가20, 1%이내 근접 1회이상

예제17: 5분봉 첫봉 양봉 + 첫봉 고가 돌파
→ A: 시세분석 > 당일분봉 > 당일 첫 분봉 캔들연속발생
     [5분] 첫분봉 기준 1봉 연속 양봉발생
→ B: 시세분석 > 당일분봉 > 분봉 금일 첫봉대비 주가등락률
     [5분] 금일 첫봉 고가대비 0봉전 종가등락률 0%이상
  C: [5분] 금일 첫봉 고가대비 1봉전 종가등락률 -0.01%이하
```

## 조건 연산자 상세 공식

### 골든크로스 / 데드크로스
```
골든크로스(상향돌파): 1봉전 A < 1봉전 B  AND  0봉전 A > 0봉전 B
데드크로스(하향돌파): 1봉전 A > 1봉전 B  AND  0봉전 A < 0봉전 B
```

### 정배열 / 역배열
```
정배열 (A > B > C): 0봉전 A > B  AND  0봉전 B > C
역배열 (A < B < C): 0봉전 A < B  AND  0봉전 B < C
```

### 추세 (2회 이상)
```
상승추세: 2봉전 A < 1봉전 A < 0봉전 A
하락추세: 2봉전 A > 1봉전 A > 0봉전 A
상승 후 하락 반전: 3봉전>2봉전>1봉전 AND 1봉전<0봉전
하락 후 상승 반전: 3봉전<2봉전<1봉전 AND 1봉전>0봉전
```

### 주요 계산 공식
```
등락률(%) = (현재값 - 기준값) / 기준값 × 100
주가위치(%) = (현재가 - 기간최저가) / (기간최고가 - 기간최저가) × 100
거래량비율(%) = (현재봉 거래량 / 기준봉 거래량) × 100
체결강도(%) = (매수체결량 / 매도체결량) × 100
```

## 피봇 포인트(Pivot) 조건 설정

### 피봇 계산 공식
```
피봇(P)    = (전일고가 + 전일저가 + 전일종가) ÷ 3
1차저항(R1) = 2 × P - 전일저가
1차지지(S1) = 2 × P - 전일고가
2차저항(R2) = P + (전일고가 - 전일저가)
2차지지(S2) = P - (전일고가 - 전일저가)
```

### 10분봉 피봇 R1 돌파 단타 조건검색식

```
=== 10분봉 피봇1차저항(R1) 돌파 조건검색식 ===

【범위지정】
A. 주가범위: 1,000원 이상 ~ 100,000원 이하
B. 거래량: 10만주 이상
C. 기타종목구분: 우선주/ETF/REITS 제외
D. 특이종목구분: 관리종목/투자경고 제외

【기술적분석】
E. 기술적분석 > 채널지표 > Pivot
   [10분] 0봉전 Pivot R1 상향돌파

■ 신호수식(수식관리자)에서 병행 확인할 추가 조건:
  - RSI(21) > 70
  - Stochastic Slow(20, 12) %K > 70
  - 현재가 > 120이평
  - 진입 타이밍: 장 시작 후 2/3/6번째 10분봉 (09:10, 09:20, 10:00)

■ 주의
  - 조건검색 = 피봇R1 돌파 종목 필터링 (넓은 그물)
  - 4개 추가 조건 = 수식관리자 신호수식으로 최종 확인 (좁은 그물)
```

## 조건검색 주요 Q&A

| 질문 | 답변 |
|------|------|
| 결과 종목이 너무 많을 때 | 범위지정에 시가총액·거래량·주가범위 조건 추가 |

| 분봉 과거검색 안 됨 | 분봉은 실시간 검색만 지원, 과거검색 불가 |
| 골든크로스 vs 이평비교 차이 | 골든크로스=이번 봉 처음 역전, 이평비교=현재 상태만 확인 |

| KRX·NXT 동시 검색 | 범위지정 > "통합" 선택 (재무조건은 KRX만) |
| 특정 시간대만 검색 | 범위지정 > 검색시간 → 09:10~09:20 형식 입력 |
| 실시간 자동 알림 | [실시간] 토글 ON → 팝업/소리 알림 |
| 분봉 시간 설정 예시 | 09:00~09:00 = 09:00:00~09:00:59 (1분 범위) |
| 시간 범위 설정 | 09:00~09:10 = 09:00:00~09:10:59 |
